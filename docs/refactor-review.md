# 重构与审查记录

本轮按“架构重构 → 规范 / 性能审查与修正 → 滚动简化”的顺序执行。
具体修改入口见 [架构导航](architecture.md)。

## 架构

- 将跨进程 DTO 与 `SessionApi` 收到 `src/shared/api.ts`，preload 只暴露白名单接口。
- main 将会话生命周期与模型设置、controls、树投影、提示词执行拆开。
- renderer 保留单一 Zustand 会话 store，以 slice 区分目录、标签页和对话状态。
- Composer、TurnView、Sidebar、Settings 按功能拆分；事件桥与思考计时脱离 React 生命周期包装。
- 注释参考 Pi 的职责、生命周期和时序说明，不重复描述代码动作。

## 审查后修正

| 问题 | 修正与回归覆盖 |
| --- | --- |
| 关闭、重开、切分支时旧异步结果覆盖新状态 | 会话实例标识、请求版本、打开 / 关闭去重及分支校验 |
| 快速连续发送让上一轮实时内容丢失 | 保留未归档的完整实时消息；明确区分乐观消息与 SDK 确认 |
| 高频 token 推送导致重复更新 | 每个动画帧合并完整快照，消息边界及时刷新 |
| 发送失败清空原稿，或覆盖后来输入 | 按会话保存失败草稿与附件；仅在安全时恢复，否则提供恢复入口 |
| 设置并发写入、授权取消与旧请求收尾互相覆盖 | 串行设置变更、分层乐观补丁、登录尝试归属及取消清理 |
| 初始化失败无法重试，准备期间模型选择丢失 | 失败后释放初始化缓存；会话发布前应用最新选择 |
| 工具过程加载失败、旧回合异步展开 | 加载错误可见且可重试，响应按回合身份检查 |
| 计时重绘整段过程、重复语法高亮和 Mermaid 全局配置竞争 | 隔离计时订阅、有界高亮缓存与加载去重、串行 Mermaid 渲染及错误回退 |
| Worktree 预检查失败仍继续操作 | 同一动作锁覆盖检查与变更；检查失败不继续，保留强制删除确认 |

## 滚动简化

取消业务层的流式翻页状态机、翻页超时、重复置顶帧循环及尺寸监听。
保留历史虚拟化，将所有实时回合改为正常文档流中的 `MessageScrollerItem`。
新回合锚定、增长跟随、用户让出控制权、导航跳转和会话恢复都使用同一个滚动入口。
导航可以先挂载一个离屏目标行，无需轮询；实时回合归档时释放旧锚点占位。
